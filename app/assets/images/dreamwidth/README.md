# Dreamwidth userhead icons

`user.png` and `community.png` are the small icons Dreamwidth shows before a
journal's name. The journal uses them the same way, so a journal looks
familiar to people who use Dreamwidth.

They're copied from Dreamwidth's source
(`htdocs/img/silk/identity/` in https://github.com/dreamwidth/dreamwidth),
which says they're taken from or based on the
[Silk icon set](http://www.famfamfam.com/lab/icons/silk/) by Mark James, and
licensed under the
[Creative Commons Attribution 2.5 License](https://creativecommons.org/licenses/by/2.5/).
